# 🍽️ Restaurant Management System

Управление бронированиями, заказами и меню ресторана с Firebase Firestore.

## 📌 Основной функционал
### Для администратора:
- Управление меню (добавление/удаление блюд)
- Просмотр статистики продаж
- Управление столиками

### Для официантов:
- Прием заказов
- Изменение статусов ("принят" → "оплачено")
- Работа с бронированиями

## 🛠 Технологии
- Python 3.9+
- Tkinter (GUI)
- Firebase Firestore
- Firebase Admin SDK
